# Shopify Prompts

用于 Shopify 店铺搭建、页面采集、主题复刻与精调、商品数据清洗与导入、SKU 导出、分类配置和促销展示的 Prompt 集合。

## 文件说明

- `页面爬取.md`：自主识别并保存网站复刻所需的代表性页面和交互参考。
- `开始复刻.md`：根据参考资料开始复刻 Shopify 主题。
- `商品CSV数据清洗.md`：检查并修复 Shopify 商品 CSV 的导入问题。
- `爬取商品SKU.md`：抓取公开商品和 SKU，并生成 Shopify CSV 与审计结果。
- `导入商品.md`：使用 Shopify CLI 导入全部商品 CSV 数据。
- `创建分类.md`：根据商品属性和网站 taxonomy 配置 Collections、Menus 等 Shopify 原生结构。
- `打折.md`：配置商品折扣及前端优惠展示。
- `页面精调.md`：依据原页面参考持续调整复刻页面，并通过浏览器或 computer use 验收。

## 使用方式

按实际任务选择对应 Markdown 文件，将其中的 Prompt 复制到 AI 编程工具中，并替换文档中用 `{{...}}` 标记的变量。

这些 Prompt 面向 Shopify 开发和数据处理流程；执行涉及线上店铺的操作前，请先确认目标店铺、主题和数据范围。

## 建议执行顺序

以下顺序适用于从参考网站搭建并运营 Shopify 店铺的常见场景；可根据现有资产跳过不需要的环节。

1. **明确范围**：确认目标店铺、主题、商品数据来源、需要复刻的页面及上线边界，并备份现有主题和商品数据。
2. **采集页面参考**：执行 `页面爬取.md`，保存首页、商品页、集合页、购物车及关键交互的参考资料。
3. **准备商品数据**：已有商品表时使用 `商品CSV数据清洗.md`；需要从公开网站整理商品时先执行 `爬取商品SKU.md`，再检查生成的 Shopify CSV。
4. **导入并组织商品**：使用 `导入商品.md` 通过 Shopify CLI 导入已校验的 CSV，随后使用 `创建分类.md` 配置 Collections、导航菜单和相关 Shopify 原生结构。
5. **复刻主题与页面**：执行 `开始复刻.md`，基于已采集的页面资料完成主题、模板和交互实现；先在开发主题中验收，不直接覆盖线上主题。
6. **精调并验收页面**：使用 `页面精调.md` 对照原页面参考修正差异，并在浏览器中验证关键页面和交互。
7. **配置促销**：在商品、分类和主题结构稳定后，使用 `打折.md` 设置折扣与前端优惠展示。
8. **上线前验证**：检查商品、分类、价格、库存、导航、移动端、购物车与折扣叠加规则；确认无误后再发布主题或启用促销。

页面复刻与商品准备可以并行，但商品导入、分类配置和促销上线应在相应数据校验完成后进行。
